Employee Management System (Flutter & Firebase)
A modern, cross-platform Flutter application designed to manage employee records efficiently. This project demonstrates the integration of Flutter with Firebase Realtime Database to perform full CRUD (Create, Read, Update, Delete) operations in real-time.

🚀 Features
•Add Employee Details: Capture and store employee information, including Name, Age, and Location.
•Real-time Data Sync: View the list of employees instantly as data is updated in the Firebase backend.
•Edit Records: Update existing employee information through an intuitive dialog interface.
•Delete Records: Remove employee entries with a single tap.
•Data Persistence: Leverages Firebase to ensure data is safely stored in the cloud.
•Clean Architecture: Separation of concerns with a dedicated DatabaseMethods class for backend logic.

🛠 Tech Stack
•Frontend: Flutter (Dart)
•Backend: Firebase Realtime Database
•Authentication: Firebase Auth (configured for future expansion)
•UI Components: Material Design 3

📦 Dependencies
The project uses several key packages:
•firebase_core: For Firebase initialization.
•firebase_database: For Realtime Database operations.
•cloud_firestore: For NoSQL document storage.
•fluttertoast: For non-intrusive user notifications.
•random_string: For generating unique identifiers.
